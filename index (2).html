    ✦ METHODOLOGY

    How It Works

    01
    📊

    Original MATLAB App

    Built with MATLAB's Regression Learner toolbox and App Designer. The original linear regression achieved an R² of ~59 % on the 14,619-record Indian housing dataset.

    02
    🐍

    Python Conversion

    Rebuilt using scikit-learn's RandomForestRegressor (300 trees). The ensemble model captures non-linear interactions, lifting R² to ~77 %.

    03
    🌐

    Web Deployment

    Flask API serves predictions in milliseconds. Packaged with Procfile for one-click Render.com deployment. Model cached via joblib for fast cold starts.

    04
    🎯

    Confidence Intervals

    Each of the 300 decision trees produces its own prediction. The 10th–90th percentile spread forms an 80% confidence band, giving an honest estimate range rather than a single point.
