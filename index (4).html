    How It Works

    Original MATLAB App

    The original project used MATLAB's Regression Learner to train a Linear Regression model with 10 input fields and a Predict button.

    Python Upgrade

    Re-implemented with scikit-learn's RandomForestRegressor (R² ≈ 77% vs ~59%), Flask backend, Pandas and NumPy data handling.

    Deploy Ready

    Packaged for Render.com with Procfile and requirements.txt. Model caches after first run for near-instant subsequent loads.

    AI Chat Assistant

    An integrated AI assistant helps you understand estimates, compare properties, and get real estate insights in real time.

    Built with Flask · scikit-learn · Chart.js · Claude AI  |  Dataset: 14,619 Indian housing transactions
