About the project

Built for fast, explainable house price estimation.

PriceWise India transforms property attributes into an instant estimated value using a machine learning pipeline trained on Indian housing data. The interface is designed like a modern SaaS dashboard, with clear signals, explainable model insight, and a focused prediction workflow.

Clean ML pipeline Flask serves a trained Random Forest model through a compatible prediction API.
Premium frontend Responsive glass panels, animated cards, theme switching, and visual feedback.
