    How It Works

    📊

    Original MATLAB App

    The original project used MATLAB's Regression Learner app to train a Linear Regression model on the dataset, then wrapped it in App Designer with 10 input fields and a Predict button.

    🐍

    Python Conversion

    We re-implemented the entire pipeline in Python using scikit-learn's RandomForestRegressor (R² ≈ 77 % vs. ~59 % for Linear Regression), Flask for the web server, and Pandas + NumPy for data handling.

    🌐

    Deployment-Ready

    The app is packaged for Render.com (free tier) with a Procfile and requirements.txt. One click and it's live for the whole world.

    Built with Flask · scikit-learn · Chart.js  |  Dataset: 14,619 Indian housing transactions
