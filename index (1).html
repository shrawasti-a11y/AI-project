About the project

Built for fast, explainable property valuation.

PriceWise India transforms property attributes into an instant estimated value using a machine learning pipeline trained on real Indian housing data. The interface is designed like a modern SaaS dashboard — clear signals, transparent model insight, and a focused prediction workflow.

Clean ML pipeline Flask serves a trained Random Forest model through a type-safe prediction API with server-side validation.
Premium frontend Responsive glass panels, animated counters, dark/light theme switching, Chart.js feature importance.

Features

Everything a polished AI product page needs.

AI valuation engine

Predicts prices from area, condition, year, postal code, schools, and airport distance using Random Forest.

Prediction history

Smart feedback

Real-time validation, loading states, shimmer animations on the submit button, and toast notifications.
